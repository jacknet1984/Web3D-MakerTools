# 🛠️ Maker Tools 3D & Laser

An all-in-one, browser-based multitool designed for makers, 3D printing enthusiasts, and laser cutter users. Create custom 3D models and laser-ready vector files instantly with zero server setup—runs 100% locally in your browser, both online and offline.

---

## ✨ Features

- 🏷️ **Text Nameplate Generator**
  - Create customized 3D nameplates and keychains.
  - Custom text inputs, system font selection, or load your own `.ttf`/`.otf` font file.
  - Adjust size, padding, border width, and hole diameter (left, top, or none).
  - Select shapes: **Rounded**, **Oval**, or **Hexagon**.

- 🖼️ **From Image to 3D**
  - Convert 2D images or logos directly into 3D printable meshes.

- 🎨 **Colours by Height**
  - Easily prepare multi-color 3D prints based on layer heights (color change at specific Z levels).

- 🖼️ **Lithophane Generator**
  - Convert photos into detailed 3D printable lithophanes.

- ⚡ **Image → SVG (Laser)**
  - Vectorize raster images into SVG format ready for laser cutting and engraving.

- 📦 **Multi-format Export**
  - Export as multicolor **3MF** files (one extruder per color).
  - Export separate **STL** files for each part.
  - Export **SVG** vector files.
  - Automatically bundled into a clean ZIP archive with an included summary.

---

## 🚀 Key Highlights

* **100% Client-Side:** No image or file is ever uploaded to a server. Your privacy is fully preserved, and processing is lightning-fast.
* **Works Offline:** Once loaded, you can save the webpage and run it anytime without an internet connection.
* **No Installation Required:** Works directly inside any modern web browser.

---

## 💻 How to Use

1. Open the tool in your web browser.
2. Choose your desired tool tab from the top menu (*Text nameplate*, *From your image*, *Colours by height*, *Lithophane*, *Image → SVG*).
3. Adjust your settings using the intuitive sidebar controls on the left.
4. Preview your design in real time using the interactive 3D preview.
5. Click **Prepare files for printing (3MF)** or **Download SVG** to save your files.
